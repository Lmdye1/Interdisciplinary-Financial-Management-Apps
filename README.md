# 学際 予算・売上計算アプリ

学園祭・学際イベント向けに、材料費・予算・売上・利益・損益分岐点を計算するWebアプリです。

## 起動方法

`index.html` をブラウザーで開くか、GitHub Pagesで公開してください。

## 主な機能

- 材料・数量・単価から材料費を集計
- 販売価格と販売予定数から売上・利益を試算
- 予備費率を含む必要予算の計算
- 損益分岐点、1杯あたり原価、時間あたり販売数の計算
- ブラウザー内への入力内容の自動保存
- **JSONファイルへの保存と、JSONファイルからの読み込み**
- 印刷・PDF出力

## 端末間で入力内容を移す方法

データベースやアカウントを使わずに、JSONファイルで端末間のデータ移行ができます。

1. 元の端末でアプリを開き、入力内容を入力します。
2. 「JSONファイルに保存」を押し、JSONファイルを保存します。
3. そのファイルをAirDrop、メール、クラウドドライブ、USBメモリなどで別の端末に移します。
4. 別の端末で同じアプリを開き、「JSONファイルを読み込む」を押して、そのファイルを選択します。
5. 確認メッセージで置き換えを承認すると、条件と材料データが反映されます。

読み込みは現在の入力内容を置き換えます。必要なら先にJSONファイルへ保存してください。読み込み後の内容は、その端末のブラウザーにも保存されます。JSONファイルには入力した情報が含まれるため、共有先と保管場所に注意してください。

## 保存の仕組み

- 通常の入力は、その端末のブラウザー内（localStorage）に自動保存されます。
- JSONファイル保存は、入力データをファイルとして書き出します。
- JSONファイル読み込みは、ファイル内のデータを検証してからアプリに反映します。
- 端末間同期用のデータベースやサーバーは使用しません。
